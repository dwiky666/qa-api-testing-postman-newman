# API Testing – Postman & Newman

This repository contains **Manual and Automation API Testing** for the Reqres.in public API using **Postman** and **Newman**.

## Scope
- HTTP methods: GET, POST, PUT, PATCH, DELETE
- Validations: status code, response time, response body

## Project Structure
- `manual/` – Manual Postman collection
- `automation/` – Automated Postman collection (with assertions)
- `reports/` – Newman HTML reports (dashboard & report)

## Tools
- Postman
- Newman
- JavaScript (Postman test scripts)
